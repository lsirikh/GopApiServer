- **`session-context.md`**: 세션별 **전용 섹션**에만 쓰기(`## [A] …` / `## [B] …`). 상대 섹션·항목 절대 미터치. prepend는 자기 헤더 아래.

- **`pipeline-state.json`**: 점유 충돌 시 `--force` 금지(human-in-loop), 문서로 추적.
- **PRD `approve`**: `advance-phase approve prd`는 **mtime 최신 PRD** 승인 → 승인 직전 자기 PRD `touch`.
