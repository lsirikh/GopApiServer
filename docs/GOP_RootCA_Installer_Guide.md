# GOP rootCA 신뢰 인증서 — 클라이언트 PC 설치 가이드

> 본 가이드는 **현장 사용자** 가 회사 노트북에 GOP 내부 HTTPS 신뢰 인증서를 1회 등록하기 위한 절차입니다.
> 약 **2분** 소요됩니다. 시스템관리자 권한이 필요합니다.

---

## 1. 준비물 점검

| 항목 | 확인 |
|------|------|
| USB 메모리 (보안팀 전달) | □ |
| USB 내 `GOP-RootCA-Installer-v1.0.0.exe` | □ |
| USB 내 `SHA256.txt` | □ |
| 노트북: Windows 10 또는 11 | □ |
| 관리자 권한 또는 임시 권한 부여 가능 | □ |

> 준비물 중 누락이 있으면 보안팀(내선 1234)에 문의해 주세요.

## 2. 설치 절차 (다음/다음/완료)

### 2-1. USB 삽입 후 파일 위치 확인

> [스크린샷 1: 탐색기 — USB:\GOP-RootCA\ 폴더 안 EXE 파일]

USB의 `\GOP-RootCA\` 폴더 안에 다음 두 파일이 있는지 확인하세요.

- `GOP-RootCA-Installer-v1.0.0.exe`
- `SHA256.txt`

### 2-2. 인스톨러 더블클릭

> [스크린샷 2: EXE 더블클릭 직후]

`GOP-RootCA-Installer-v1.0.0.exe` 를 더블클릭합니다.

### 2-3. (필요 시) SmartScreen 경고 대응

> [스크린샷 3: Windows SmartScreen "PC를 보호했습니다" 파란 화면]

폐쇄망 자체 서명 인증서이므로 처음에는 Windows 보호 경고가 뜰 수 있습니다.

1. **"추가 정보"** 를 클릭
2. **"실행"** 버튼 클릭

### 2-4. UAC 권한 허용

> [스크린샷 4: "이 앱이 디바이스를 변경할 수 있도록 허용하시겠어요?" 다이얼로그]

**"예"** 를 클릭하세요. (관리자 권한 없으면 IT팀에 임시 권한 요청)

### 2-5. 한국어 마법사 진행

> [스크린샷 5: Inno Setup 환영 화면]

#### 화면 1 — 환영

**"다음(N) >"** 클릭

#### 화면 2 — 안내문 동의

본문을 읽고 **"동의함(A)"** 선택 → **"다음(N) >"** 클릭

#### 화면 3 — 설치 준비 완료

**"설치(I)"** 클릭

#### 화면 4 — 진행률 표시 (3~5초)

진행률 바가 표시됩니다. 조작 불필요.

#### 화면 5 — 완료

> [스크린샷 6: "설치 완료" 마침 화면]

**"마침(F)"** 클릭

## 3. 설치 확인 (선택)

PowerShell을 일반 사용자 권한으로 실행하고 아래 명령을 입력하세요.

```powershell
Get-ChildItem Cert:\LocalMachine\Root | Where-Object Subject -Match 'mkcert'
```

**1행 이상** 출력되면 정상입니다.

또는 시작 메뉴에서 `certmgr.msc` 검색 → 실행 → "신뢰할 수 있는 루트 인증 기관" → "인증서" → `mkcert development CA ...` 항목 표시 확인.

---

## 4. 사용 — HTTPS 정상 동작 확인

브라우저에서 `https://api.gop.local:8443/health` 또는 `https://central.gop.local/` 접속 시 **자물쇠 아이콘** 이 정상 표시되어야 합니다.

> [스크린샷 7: 브라우저 주소창 자물쇠 아이콘 정상 표시]

만약 여전히 "이 사이트는 안전하지 않습니다" 가 뜬다면:

1. 브라우저 완전 종료 후 재시작
2. 그래도 안 되면 본 가이드 §5 트러블슈팅 참조

---

## 5. 트러블슈팅 빠른 표

| 증상 | 1차 조치 |
|------|---------|
| SmartScreen 경고가 계속 뜸 | "추가 정보 → 실행" 클릭, 1회만 필요 |
| UAC 프롬프트가 안 뜸/거부됨 | 시스템관리자 권한 요청 (IT팀) |
| 설치는 완료됐는데 브라우저에서 여전히 경고 | 브라우저 완전 종료 후 재시작, `ipconfig /flushdns` |
| 백신이 EXE를 격리 | SHA256 값을 보안팀에 전달하여 화이트리스트 요청 |
| 다른 버전이 이미 깔려있다고 표시 | 제어판에서 구버전 제거 후 재설치 |
| 설치 로그 위치 | `%TEMP%\GOP-RootCA-Install.log` (마지막 줄 `Result=SUCCESS` 확인) |

---

## 6. 제거 (필요 시)

1. **시작 → 설정 → 앱 → 설치된 앱** (또는 제어판 → 프로그램 추가/제거)
2. 목록에서 **"GOP rootCA Installer 1.0.0"** 찾기
3. **"제거"** 클릭 → UAC "예" 클릭
4. 자동으로 신뢰 인증서까지 제거됩니다.
